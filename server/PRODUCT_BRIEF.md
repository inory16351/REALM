# 제품 개요

- 목표: 5~10인이 각자 기기에서 방 코드로 접속해 플레이하는 한국어 실시간 웹 보드게임.
- 플랫폼: 최신 데스크톱 브라우저, 가로 화면, 최소 1024×700.
- 전달물: Cloudflare Worker, Durable Object, 번들 정적 웹 클라이언트.
- 한 판: 약 15~40분. 네 번의 버리기와 비밀 직업 추리를 거쳐 총점 순위를 정한다.
- 네트워크: WebSocket 기반 실시간 방. 방별 게임 상태와 재접속 세션은 Durable Object에 저장한다. 장기 전적·랭킹은 첫 버전 범위 밖이다.
- 성능 예산: 별도 로딩 없이 즉시 시작, 60fps 목표. 이미지·오디오 의존성 없음.
